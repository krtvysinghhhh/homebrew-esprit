# Homebrew Esprit Tap

Official Homebrew tap for [Esprit](https://github.com/krtvysinghhhh/Esprit) — the autonomous workspace & operating layer for developers.

## Installation

### Instant Install (Recommended)
You can install Esprit with a single command:
```bash
brew install krtvysinghhhh/esprit/esprit
```

### Manual Tap & Install
Alternatively, tap the repository first and install:
```bash
brew tap krtvysinghhhh/esprit
brew install esprit
```

### Install Latest Development Build (From Source)
To compile and install the bleeding-edge `main` branch:
```bash
brew install --HEAD krtvysinghhhh/esprit/esprit
```

## Quick Start
```bash
# System & AI diagnostic
esprit doctor

# Deep system cleaner (dry run preview)
esprit clean --dry-run

# Codebase question answering
esprit ask "explain this project architecture"

# View all commands
esprit --help
```
